# OfficeQuest 13 — ระบบเกมมิฟิเคชัน รายวิชาการใช้เครื่องใช้สำนักงานดิจิทัล (ระดับ ปวช.)

ระบบเกมมิฟิเคชันและเอกสารออกแบบการสอนที่พัฒนาขึ้นให้สอดคล้อง **ครบทั้ง 13 บทเรียน** ตามสารบัญหนังสือเรียนรายวิชา **การใช้เครื่องใช้สำนักงานดิจิทัล ระดับ ปวช.**

## วิธีเปิดใช้งาน (เล่นได้ทันที 100% Offline)
1. ดับเบิลคลิกที่ไฟล์ **`index.html`** เพื่อเปิดบนเว็บเบราว์เซอร์ (Chrome / Edge / Safari / มือถือ) ได้ทันทีโดยไม่ต้องติดตั้งเซิร์ฟเวอร์หรือต่ออินเทอร์เน็ต
2. กรอกชื่อ-นามสกุล รหัสนักศึกษา ชั้น/กลุ่ม และเลือกตัวละคร (Avatar) เพื่อเริ่มภารกิจ
3. **เข้าสู่โหมดครูผู้สอน (Teacher Dashboard):** กดปุ่ม **"โหมดครู"** มุมขวาบน รหัสผ่านเริ่มต้นคือ **`1234`** (สามารถดูสถิติรายบุคคล เปรียบเทียบ Pre/Post-Test และกด **ส่งออก CSV** เพื่อนำไปเปิดใน Microsoft Excel ภาษาไทยได้ทันที)

## โครงสร้างไฟล์ในโปรเจกต์
- `index.html` — หน้าเว็บแอปหลักของเกม OfficeQuest 13
- `css/style.css` — สไตล์ UI ระบบเกมมิฟิเคชันและรูปแบบสั่งพิมพ์เกียรติบัตร
- `js/data_core.js` — โครงสร้าง 4 โซน, 6 ตำแหน่งงาน, 10 เหรียญตรา, และข้อสอบ Pre-Test / Post-Test (13 ข้อ บทละ 1 ข้อ)
- `js/data_units_1_7.js` — เนื้อหา มินิเกม และแบบทดสอบ บทเรียนที่ 1–7
- `js/data_units_8_13.js` — เนื้อหา มินิเกม และแบบทดสอบ บทเรียนที่ 8–13
- `js/minigames.js` — เอนจินมินิเกมจำลองสถานการณ์ 7 รูปแบบ (แยกประเภท, สถานการณ์รับสาย/เลือกเครื่อง, เครื่องคำนวณเลข 10-Key, แผงควบคุมเครื่องถ่ายเอกสาร/โทรสาร, แคชเชียร์ POS & รหัสแท่ง EAN-13, เรียงลำดับรูปเล่ม/สายพานผลิตเอกสาร, ห้องแล็บ Search Engine & E-mail)
- `js/teacher.js` — โหมดครูผู้สอนและการส่งออกคะแนน CSV (UTF-8 BOM)
- `js/sound.js` — ระบบเสียงเอฟเฟกต์สังเคราะห์ด้วย Web Audio API (ไม่ต้องใช้ไฟล์เสียงภายนอก)
- `js/app.js` — ระบบจัดการสถานะผู้เล่น XP เหรียญตรา และเกียรติบัตรดิจิทัล
- `docs/คู่มือออกแบบเกมมิฟิเคชัน_การใช้เครื่องใช้สำนักงานดิจิทัล_ปวช.md` — เอกสารแผนการออกแบบเกมมิฟิเคชันและคู่มือครูผู้สอนฉบับสมบูรณ์
